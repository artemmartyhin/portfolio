Selected work

balq

2026 · Rust · open source

Local, verified history of any contract's storage on a plain full node. No archive node, no indexer schema. Built on EIP‑7928 block‑level access lists: it indexes a contract back to its deploy, follows the head, and verifies every block it stores.

balq get 0x3582… --field "balances[0x61Cc…]" --block 114591
→ balances[0x61Cc…] = 37585   (slot 0xc0e2…, set @ 114590, bal)
