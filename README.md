# artemmartyhin.vercel.app

Personal site. Plain HTML and CSS, no build step.

- `index.html`, `styles.css`, `script.js` — the page (hero field animation, live mainnet head)
- `assets/` — photo, CV, favicon

Deployed by Vercel from `main`: the build step just copies the files into `dist/`. To preview locally: `python3 -m http.server` in this directory.
